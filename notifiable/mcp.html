Using Notifiable from external AI assistants (MCP)

Notifiable declares a rovo:mcp module named Notifiable reporting that exposes seven tools. They are the same actions the Reporting Officer agent uses.

Tool Verb What it does
assess-incident GET DORA classification of an incident, per criterion with evidence, plus applicable regimes and live deadlines
reporting-deadlines GET Upcoming and overdue DORA, GDPR and NIS2 deadlines, plus incidents awaiting classification
draft-incident-report CREATE Saves a new draft of the next report, field by field. Never submits
record-classification UPDATE Records the human major / not-major decision. Confirm with the user first
record-submission UPDATE Records a filing and the authority reference. Confirm with the user first
find-recurring-incidents GET The RTS 2024/1772 Art. 8(2) recurring-incident check
explain-reporting-rule GET Plain-language rule with its citation

Every call runs with the invoking user's permissions. Results only include incidents that user can open.

In Rovo Studio

Go to Create agent → Tools → Add tools → Connected apps → Notifiable and pick the tools you want. The bundled Reporting Officer agent already uses all of them through the notifiable-incident-reporting skill.

In Claude Code, Claude Desktop, Cursor or VS Code (Early Access)

  1. An org admin enables the tools under admin.atlassian.com → Apps → Sites → (site) → Connected apps → Notifiable → Tools.
  2. Add the server. Notifiable's server URL is:
    claude mcp add --transport http notifiable https://mcp.atlassian.com/forge/f62df724-c85c-4739-808d-2a9cdc5b0559
    For other clients, add an HTTP MCP server with the same URL.
  3. Authenticate with OAuth in the browser, pick the site and approve the scopes.
  4. Optional: give your agent the Notifiable skill as a skill or system prompt.

Example prompts:

  • "Which regulatory deadlines are due today?"
  • "Is LPOPS-101 major under DORA, and why?"
  • "Draft the initial notification for LPOPS-101."

External MCP clients are an Early Access feature of Forge rovo:mcp. Tool availability depends on the admin's Connected-apps settings.
